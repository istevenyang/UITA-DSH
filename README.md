# UITA-DSH
**UITA-DSH (Universal Intelligent Test Architecture With Deterministic Skill Harness &amp; Cross-Platform UI Automation Runtime)** 是一个将 **AI 探索式规划（DSH）**、**受控风险单测与真机验证（Sentinel）**、**本地五维知识图谱飞轮（`.dsh/knowledge`）** 与 **确定性跨平台 UI 自动化执行（TCS / TestCaseScript + Rosetta 多层自愈定位）** 深度融合的通用智能测试架构与运行时。
